# Mamelis Care

This is a static Astro site. Run `npm run check`, `npm run lint`, `npm test`, and `npm run build` after changes. `npm run test:e2e` checks the generated site in Chromium after a build.

- Read `docs/cms/INTEGRATION.md` before changing CMS behavior. `docs/cms/` is generated by `npm run cms:docs`; do not edit it manually.
- Fetch authenticated CMS content only at build time in Astro frontmatter or static endpoints. Never ship tokens in browser scripts or public environment variables.
- Route pages from their delivered `entry.url`, preserve menu order, and use durable CMS media URLs directly. Do not copy media into a public immutable cache.
- Fail builds on CMS errors or conflicting routes. Content changes require a complete rebuild.
- Preserve Dutch content, the existing design, accessible navigation and native FAQ disclosures.
- Coolify serves `dist/` as a static site. See `deploy/nginx.conf` and README for redirects, 404s and CMS-triggered rebuilds.
